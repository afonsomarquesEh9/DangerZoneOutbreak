# 🎮 Danger Zone: Outbreak

Jogo desenvolvido em Python utilizando Pygame, inspirado nos clássicos jogos de tiro e sobrevivência.

O projeto foi baseado em um repositório existente, que clonei e modifiquei para explorar novas funcionalidades, realizar melhorias e aprofundar meus conhecimentos em Python e programação orientada a objetos.

### 🛠️ Tecnologias

* Python
* Pygame
* Git e GitHub

### 🎯 Objetivo

Projeto desenvolvido para fins de aprendizado, com foco na prática de programação, organização de código e desenvolvimento de jogos.
